## Overview

This is a minimal HTML-based project demonstrating web development concepts and the OpenSpec workflow. The main artifact is `hello-world.html`, which showcases:

- **Layout**: A flexbox-based layout with a fixed-width sidebar (250px) on the left and main content area on the right
- **Sidebar**: Contains an "about" section explaining the project's purpose
- **Visual Design**: Night sky theme using a gradient background (dark blues/purples) with semi-transparent overlays
- **Interactive Effect**: A cursor lamp effect that illuminates areas under the mouse pointer using CSS custom properties and JavaScript event listeners
- **Styling**: All CSS is embedded inline within the HTML file for simplicity
