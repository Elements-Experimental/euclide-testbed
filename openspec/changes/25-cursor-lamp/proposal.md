## Why

The hello world page currently displays a static night sky theme. Adding a cursor lamp effect will create an interactive visual experience where the user's cursor acts as a light source that illuminates the surrounding area, enhancing the immersive quality of the night sky aesthetic.

## What Changes

The existing hello-world.html page will be enhanced with JavaScript and CSS to implement a cursor-following lamp effect. As the user moves their cursor across the page, a radial gradient "spotlight" will follow the cursor position, creating the illusion of a lamp illuminating the dark night sky.

## Capabilities

### New Capabilities
- `cursor-lamp`: Interactive cursor effect that creates a radial light gradient following the mouse position across the page

### Modified Capabilities
- `hello-world-page`: The existing hello world page will be enhanced with cursor interactivity while maintaining its night sky theme

## Impact

- Existing hello-world.html file will be modified to add JavaScript and additional CSS
- No new files required
- No external dependencies needed (vanilla JavaScript and CSS)
- Backward compatible - page will still display properly if JavaScript is disabled (just without the lamp effect)
